# Règles du projet StageFlow

- Respecter docs/qualite/definition-of-done.md pour chaque story.
- Écrire les critères d'acceptation selon docs/qualite/template-criteres.md.
- Ne jamais modifier un scénario Cucumber fourni par l'enseignant.
- Données fictives uniquement, aucun secret dans le code.
- Aucun commit direct sur main : toujours une branche et une pull request.
